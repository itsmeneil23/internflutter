# Clothy

Clothy is an e-commerce frontend application built with Flutter. It provides a user-friendly interface for browsing and purchasing clothing items.

## Setup Instructions

To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/itsmeneil23/internflutter.git
   ```

2. Navigate to the project directory:
   ```bash
   cd internflutter/clothy
   ```

3. Install the dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```

## Usage Guidelines

- Browse the available clothing items on the home screen.
- Add items to the cart by clicking the "Add to Cart" button.
- View the cart and proceed to checkout.
- Fill in the required information and place the order.
